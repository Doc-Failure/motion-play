# Motion Play UI artwork

Source: the user-supplied `motion-play-ui-pack.zip` (elements directory).
`ui-pack-manifest.json` maps every supplied PNG element to its local WebP derivative.
The images are resized for web display with cwebp (quality 86, alpha quality 100).
No art is generated, redrawn or uploaded during conversion; transparency is retained.

Usage:
- Paper, clouds, rainbow, children and title cloud: homepage and menu scenery.
- Colored panels: home actions and compact game catalog stickers.
- Play, catalog, trophy: home action icons; play also appears in the camera lobby.
- Camera and players callouts: homepage guidance, paired with accessible HTML text.
- Garden border and doodle accents: menu decoration.
- Trophy: round/tournament result decoration.
- Settings icon: retained with the pack for future use; no settings screen is added.

The archive's pages, typography sheets and variations are visual references rather
than executable pages or web fonts. Production labels remain HTML text; the
full-page mockups are not shipped as page screenshots. Previous user decisions
(camera-first play, player count only, direct starts) take precedence over controls
pictured in those references.
