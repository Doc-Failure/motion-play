# Original EyeToy: Play — Motion Play coverage

The comparison covers the original 2003 game, not Play 2/3 or their bonus games.
Regional titles below refer to the same minigame. Current Motion Play versions
are original adaptations/prototypes, not verified replicas of every original rule.

| Original minigame (EU / US aliases) | Current status |
| --- | --- |
| Beat Freak | Paper Jam — visible |
| Kung Foo | Paper Dojo — visible |
| Wishi Washi | Window Wipe — visible |
| Keep Ups / Soccer Craze | Keep Ups — visible; original body-contact football adaptation |
| Boxing Chump | Cardboard Champ — visible; original opponent-based boxing adaptation |
| UFO Juggler | Implemented: spin/coast engines and rescue pilots; original adaptation; maintain UFOs and deal with attacking ships |
| Slap Stream | Needs a dedicated enemy/friendly target game; generic Whack-a-Mole prototype is hidden |
| Plate Spinner | Older implementation exists but remains hidden for quality work |
| Boogie Down / Disco Stars | Needs a dedicated dance adaptation; generic Dance Challenge prototype is hidden |
| Ghost Catcher / Ghost Eliminator | Implemented as Ghost Catcher; rub paper ghosts, swat bats, stop escapes |
| Mirror Time | Missing; target hitting with flipped/rotated views |
| Rocket Rumble | Existing adaptation hidden at the user's request; needs rework |

Bubble Battle is also hidden at the user's request. Its implementation is retained.
The catalog includes UFO Juggler and Ghost Catcher alongside Paper Dojo, Window Wipe, Paper Jam, Cardboard Champ and Keep Ups;
the tournament retains the latter five distinct games once each and totals points.

Sources: [Sony game manual, pp. 14–15, archived scan](https://db.hfsplay.fr/files/2019/12/02/EyeToy_-_Play_USA_XomAEr4.pdf),
[regional names and game descriptions](https://en.wikipedia.org/wiki/EyeToy:_Play).
Local implementation status is based on repository inspection, not the sources.
